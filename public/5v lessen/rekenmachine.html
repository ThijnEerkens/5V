Deploy to GitHub Pages Guide

Follow these quick steps to host this web application for free on GitHub Pages:

  1. Create a new repository on GitHub.com.
  2. Name your project (e.g., quantum-calculator).
  3. Create a file named index.html in your repository.
  4. Paste this entire file source code into index.html and commit.
  5. Go to Settings -> Pages in your GitHub repository.
  6. Set the branch to main / root and click Save!
